# Проверка Gold-кандидата benchmark масштабируемости

Gold-кандидат подготовлен только по входным `SpecificationReq`. Результаты
`B0_RULE`, `B1_ONESHOT` и `FULL` при разметке не использовались. До проверки
двумя независимыми экспертами его метрики считаются предварительными.

Каждый эксперт независимо проверяет все 20 проектов по шкале 1–5:

- правдоподобие предметной области;
- корректность акторов и границ Use Case;
- полноту обязательных этапов;
- корректность альтернативных и ошибочных ветвлений;
- обоснованность связей `FR → Use Case`;
- отсутствие неподтверждённых функций.

Оценки 1–2 требуют решения `revise` и комментария. После двух независимых
проверок рассчитываются точное совпадение, совпадение с допуском ±1 и
линейно-взвешенная κ Коэна. Исходные формы сохраняются даже после согласования
спорных элементов.

Техническая фиксация Gold-кандидата запрещает менять разметку после просмотра
результатов систем. Любая исправленная версия получает новый хеш и отдельную
запись изменения.
