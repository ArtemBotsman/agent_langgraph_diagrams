# Протокол сравнения на 20 проектах разного размера

Дата фиксации: 2026-09-15.

## Исследовательский вопрос

Как изменение числа функциональных требований влияет на содержательное
качество, формальную принимаемость, трассировку и стоимость прямой генерации
`B1_ONESHOT` и полного графа `FULL` при использовании одной базовой модели?

## Данные

- 20 `SpecificationReq`, полученных от научного руководителя;
- четыре группы по пять проектов;
- фактические диапазоны: 6–10, 12–19, 24–48 и 54–74 ФТ;
- Gold-кандидат подготовлен только по входным требованиям до сравниваемых
  запусков;
- SHA-256 Gold-кандидата:
  `f5e729074ec9c3d48c12f257dd20ef0134b18f8a26868a1a0796d68b9cd20270`.

## Сравниваемые условия

- `B1_ONESHOT`: один прямой вызов LLM формирует полный комплект артефактов;
- `FULL`: два специализированных подграфа, детерминированные проверки,
  критика и ограниченное исправление.

Внутри сравнения фиксируются provider, model ID, вход, версия prompt,
структура результата, evaluator и локальная модель сходства.

## Основные метрики

- `Actor F1`;
- `UC F1`;
- `Milestone Recall`;
- `Branch Recall`;
- `Trace F1`;
- `FR Coverage`;
- `Activity Element Trace Coverage`;
- `E2E Success`.

Дополнительно измеряются задержка, вызовы LLM, токены, расчётная стоимость,
число исправлений и устойчивость повторов. Агрегированный смысловой показатель
не используется как единственное основание вывода.

## Порядок запуска

1. Контрольный малый кейс `SCALE-001` для проверки совместимости.
2. По одному заранее выбранному кейсу из следующих групп: `SCALE-010`,
   `SCALE-015`, `SCALE-020`.
3. Первый повтор всех 20 проектов только после успешной проверки лимитов.
4. Второй и третий повторы выполняются после оценки фактической стоимости.

## Правила остановки

- ответ обрезан провайдером;
- локальный предел вызовов или токенов исчерпан;
- расчётная стоимость достигает установленного для запуска ограничения;
- повторяется одна блокирующая ошибка, которую система не может исправить в
  установленное число попыток.

Остановка считается результатом `E2E = 0`, а потраченные время и токены
сохраняются. Неуспешные ответы не исправляются вручную и не исключаются из
среднего.

## Ограничение вывода

Gold остаётся авторским кандидатом до проверки двумя независимыми экспертами.
Поскольку черновик разметки подготовлен с помощью `deepseek-flash`, сравнение
на той же модели может содержать модельное смещение. Автоматические значения
следует считать предварительными, а экспертные формы — обязательной проверкой.
