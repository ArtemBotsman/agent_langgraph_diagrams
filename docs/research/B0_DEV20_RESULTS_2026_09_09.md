# B0 full DEV20 — results and interpretation

Date: 2026-09-09. Experiment:
`artifacts/benchmark_runs/b0-dev20-r3-2026-09-09/results.json`.

## Protocol

- Condition (условие): `B0_RULE`, a deterministic rule-based baseline.
- Data: all 20 development cases; sealed hidden cases were not invoked.
- Repeats: 3 per case, 60 runs in total.
- LLM calls and tokens: 0.
- Semantic backend: local multilingual candidate matcher.
- Unit of statistical analysis: a benchmark case, not an individual repeat.
- Confidence interval: deterministic percentile bootstrap over 20 case means,
  10,000 resamples. Repeats are not treated as independent observations.

## Main result

- technical completion: 60/60; mean `end_to_end_success = 1.000`;
- repeat stability: `1.000`;
- semantic composite: `0.408`, case-level SD `0.123`, bootstrap 95% CI
  `[0.356; 0.463]`;
- actor F1: `0.183`;
- Use Case F1: `0.675`;
- scenario milestone F1: `0.240`;
- branching F1: `0.100`;
- trace F1 against gold projection: `0.685`;
- hallucination proxy: `0.493`, bootstrap 95% CI `[0.432; 0.548]`;
- mean latency: about `1.0 ms` on the current machine;
- token cost: 0.

The result is not a contradiction: B0 always creates a schema-valid,
trace-linked artifact, so technical E2E succeeds. However, it has no language
model capable of interpreting domain-specific actors, multiple business goals,
milestones and branches. Consequently, formal validity is high while semantic
agreement with the author gold is low.

## Complexity effect

- simple cases (`n=6`): semantic `0.543`, hallucination proxy `0.396`;
- medium cases (`n=9`): semantic `0.359`, hallucination proxy `0.522`;
- hard cases (`n=5`): semantic `0.335`, hallucination proxy `0.556`.

This is descriptive evidence only: the groups are small and the benchmark is
synthetic and author-labelled. It supports the next hypothesis, but does not by
itself prove statistical superiority of FULL.

## Research conclusion

B0 is a strong reproducibility and lower-cost control, but a weak semantic
solution. Its role is to show that schema checks, trace links and Mermaid
rendering do not replace interpretation of requirements. B1 and FULL must now
be evaluated under the same input, output contract and evaluator. A conclusion
about the benefit of critic/repair requires the full repeated DEV comparison,
expert review and only then the one-time hidden run.
