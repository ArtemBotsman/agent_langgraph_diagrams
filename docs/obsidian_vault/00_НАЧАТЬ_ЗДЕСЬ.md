# Навигация по проекту AgentLangGraph

Эту папку можно открыть в Obsidian (программа для связанных заметок) как
отдельное хранилище. Начинать работу следует с этой страницы.

## Главный вывод после повторной проверки созвонов

В проекте **два агента**, а не шесть:

1. `Use Case Agent` (агент вариантов использования) — превращает требования в
   структурированный набор сценариев.
2. `Activity Diagram Agent` (агент диаграмм активности) — превращает каждый
   сценарий в структурированную модель диаграммы активности.

`Root Graph` (корневой граф) связывает агентов и не считается третьим агентом.
`Generator` (генератор), `Critic` (критик) и `Repair` (исправление) — внутренние
роли/вершины этих двух агентов, а не самостоятельные агенты.

  `docs/defense/GRAPH_AND_RESEARCH_DEFENSE_GUIDE.md`.

## Статус на 09.09.2026

- Структура двух агентов спроектирована.
- `Use Case Agent` (агент вариантов использования) имеет проверенный
  `ScriptedLLMClient` (тестовый клиент с заранее заданными ответами).
- `Activity Diagram Agent` (агент диаграмм активности) пока содержит
  `stub` (заглушки) вместо живых обращений к модели.
- Ключ DeepSeek перенесён в локальный `.env` (файл переменных окружения),
  который исключён из Git (системы контроля версий).
- DeepSeek-ключ и модель `deepseek-v4-flash` проверены минимальным вызовом:
  HTTP 200, 91 токен. Это техническая проверка связи, а не эксперимент качества.
