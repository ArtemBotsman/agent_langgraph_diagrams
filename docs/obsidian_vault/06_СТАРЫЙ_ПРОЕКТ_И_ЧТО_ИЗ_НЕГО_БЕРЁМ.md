# Сравнение со старым проектом diagrams_generation_agents — копия 3

Локальная историческая копия `diagrams_generation_agents — копия 3` находится
вне текущего репозитория.

![[assets/05_reference_comparison.png]]

## Что фактически делает старый проект

Старый `DiagramsGenerationGraph` (граф генерации диаграмм):

- параллельно запускает генерацию компонентной диаграммы;
- для каждого уже существующего варианта использования запускает подграф;
- в подграфе параллельно получает простую диаграмму вариантов использования и
  диаграмму активности;
- языковая модель сразу возвращает Mermaid (текст диаграммы).

В старом проекте нет отдельного исполняемого агента-архитектора. Каталог
`agents/architect/diagrams` обозначает предметную область. Фраза «ты аналитик и
архитектор» — роль в prompt (инструкции модели).

## Что полезно перенять как идею

- `Send` (динамическая отправка состояния) для запуска обработки каждого
  варианта использования;
- `context_schema` (контракт контекста) для передачи LLM-клиента;
- `checkpointer` (механизм контрольных точек) и `thread_id` (идентификатор
  выполнения) для последующего возобновления;
- отдельный подграф обработки одного варианта использования;
- сохранение `source_use_case_index` (индекса исходного варианта).

Перед переносом кода нужна отдельная проверка лицензии: в копии проекта файл
лицензии не найден.

## Что нельзя переносить как основное решение

- прямую генерацию Mermaid без промежуточной типизированной модели;
- компонентную диаграмму — она исключена из текущего обязательного scope
  (границ задачи);
- отдельную Use Case Diagram (диаграмму вариантов использования) — текущая НИР
  требует структурированные варианты и Activity Diagram (диаграмму активности);
- отсутствие детерминированного валидатора;
- отсутствие Critic (критика), ограниченного Repair (исправления) и полной
  двусторонней трассировки;
- жёстко записанные ключи API (интерфейса доступа к модели).

## Критическая находка безопасности

В `experiments/test_digrams_generation.py` старого проекта найден жёстко
записанный ключ DeepSeek. Его значение здесь намеренно не приводится. Этот ключ
следует отозвать в кабинете DeepSeek и больше не использовать. В текущий проект
он не копировался.
