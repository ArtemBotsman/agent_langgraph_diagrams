# Два агента и три графа

## Root Graph (корневой граф)

Это служебный оркестратор. Он не является отдельным агентом.

Последовательность:

1. `normalize_requirements` (нормализовать требования);
2. `run_use_cases` (запустить агента вариантов использования);
3. `run_activities` (запустить агента диаграмм для каждого варианта);
4. `validate_e2e_trace` (проверить сквозную трассировку);
5. `run_evaluator` (рассчитать метрики);
6. `finalize_pipeline` (сформировать итог).

Статический размер: 6 рабочих вершин и 7 рёбер.

## Use Case Agent (агент вариантов использования)

Назначение: преобразовать весь `SpecificationReq` (входной запрос) в один
согласованный `UseCaseSet` (набор вариантов использования).

Внутренний порядок:

1. подготовка требований;
2. `Generator` (генератор) создаёт структурированный набор;
3. `Schema validation` (проверка схемы);
4. `Deterministic validation` (детерминированная проверка);
5. `Critic` (критик) оценивает смысл;
6. `Router` (маршрутизатор) выбирает завершение, исправление или отказ;
7. `Repair` (исправление) получает точные ошибки и возвращает результат на все
   проверки;
8. контролируемое успешное или неуспешное завершение.

Статический размер: 9 рабочих вершин и 13 рёбер. Дополнительное условное ребро
пропускает дорогой critic при уже известной формальной ошибке.

## Activity Diagram Agent (агент диаграмм активности)

Назначение: получить один `Use Case` (вариант использования) и сформировать одну
структурированную `ActivityDiagram` (диаграмму активности).

Внутренний порядок повторяет первый агент, но после успешной проверки выполняет
`render_mermaid` (рендеринг в Mermaid).

Статический размер: 10 рабочих вершин и 14 рёбер. Дополнительное условное ребро
направляет формальный дефект сразу в decide/repair.

Этот агент запускается отдельно для каждого варианта использования. Поэтому
число фактических выполнений зависит от числа полученных вариантов и количества
исправлений.

## Что является агентом, а что нет

- Генератор + критик + цикл исправления в одном подграфе — один агент.
- Детерминированный валидатор — обычная функция, не агент.
- Маршрутизатор — логика выбора ребра, не агент.
- Рендерер Mermaid — обычная функция, не агент.
- Корневой граф — оркестратор, не агент.
