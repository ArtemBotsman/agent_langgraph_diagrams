# ADR-004: Единый TraceManifest

- **Дата:** 2026-08-21
- **Статус:** Accepted

## Решение
Все связи хранятся в `TraceManifest`; индексы производны.

## Альтернативы
Двусторонние поля на сущностях; трассировка только в тексте/Mermaid.

## Последствия
+ Одна точка правды при repair; детерминированная integrity-проверка.  
− Нужен этапный merge манифеста между subgraphs.
