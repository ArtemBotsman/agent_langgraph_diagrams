# Сообщение об экспериментальном запуске

Анастасия Алексеевна, добрый день!

Для сопоставимого сравнения pipeline с сильными внешними моделями используется
единый протокол. Для всех вариантов выбраны три
одинаковых development-входа (`B1-DEV-002`, `B1-DEV-010`, `B1-DEV-020`), один
выходной JSON-контракт и один evaluator. Hidden-кейсы и gold-разметка в пакет не
включены.

Для запуска GPT внутри pipeline используется скрипт:
`scripts/run_benchmark_experiment.py`. Он запускает два условия —
`B1_ONESHOT` с одним обращением к модели и `FULL` с двумя агентами, критиком,
ограниченным исправлением и детерминированными проверками. Команда и ограничения
по числу вызовов и токенов приведены в приложенной инструкции
`EXTERNAL_MODEL_EXPERIMENT_HANDOFF.md`.

Для Claude в архиве
`AgentLangGraph_external_comparison_DEV3_portable_2026-09-11.zip` находятся:

- единый prompt `CLAUDE_PROMPT_RU.md`;
- три `SpecificationReq`;
- точная JSON Schema результата;
- инструкция по сохранению трёх независимых повторов каждого кейса.

Нужно вернуть исходные JSON-ответы без ручного исправления и указать точное
название/model ID. Если интерфейс показывает tokens, latency или cost, эти
значения также нужно сохранить. API-ключ присылать не нужно.

После получения файлов ответы импортируются через тот же parser,
детерминированные валидаторы, построение TraceManifest, Mermaid renderer и
evaluator. В общей таблице будут E2E success, Actor/Use
Case/Milestone/Branch/Trace F1, неподтверждённые элементы, стабильность,
задержка, токены и стоимость.

Основной экспериментальный вопрос: насколько результат зависит от силы модели
и даёт ли полный многошаговый граф преимущество по надёжности и трассировке по
сравнению с одним запросом той же модели.
