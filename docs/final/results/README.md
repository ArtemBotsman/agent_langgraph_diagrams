# Числовое приложение

`results_snapshot.json` содержит показатели из неизменяемых локальных срезов:

- `large_cap2`: четыре запуска на 59/74 ФТ, лимит $2;
- `sizes_original24`: исходные 24 попытки на шести проектах;
- `temperature_pilot`: все 24 позиции, включая восемь не начатых;
- `diagnostic_retries`: четыре отдельно разрешённых повтора.

Для каждого источника сохранён SHA-256 исходного summary.json. Числа перенесены
без округления. Отсутствующие значения не заменены нулём. Повторы не подменяют
исходные попытки; старые cap1 не включены в cap2. Временные отметки,
локальные пути, требования и ответы модели не входят в публичный срез.
Длительность сохранена как метрика эффективности.

В `activity_v2` разделены основания: корректная ссылка, структурный элемент,
явное неподтверждённое предположение и ошибки основания. Допустимое формальное
основание не равнозначно семантическому подтверждению элемента.

Средние по размерам считают сначала по общим доступным повторам проекта,
затем поровну по проектам. Доступные пары различаются между метриками.
Известный отказ без пакета даёт ноль доставки структуры, Gold остаётся NA.
Прерванный FULL на 12 ФТ с неизвестным расходом выделен отдельно.
Резерв $0.167234700 — верхняя оценка, не измеренная цена.

Срез достаточен для проверки чисел, но не повторного сопоставления с Gold:
закрытые входы и тексты Gold не публикуются. Gold — авторский кандидат,
не независимая экспертная разметка.
