# Итоговые материалы технологического проекта

В публичном репозитории оставлены две актуальные версии:

- `AgentLangGraph_technology_project_resit_v2_2026-09-11.pptx` — презентация;
- `AgentLangGraph_technology_report_final_2026-09-11.pdf` — полный технический
  отчёт.

Числа в этих материалах восстанавливаются из сохранённых результатов в
`artifacts/`. Методика и ограничения описаны в
`docs/research/TECHNOLOGY_PROJECT_COMPARISON_2026_09_11.md`.

Передаточные ZIP-пакеты, редактируемый DOCX и предыдущие версии презентации
хранятся локально и не входят в публичный репозиторий. Распакованные входы,
схемы и скрипты внешнего эксперимента доступны в `experiments/` и `scripts/`.
