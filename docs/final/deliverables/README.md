# Итоговые материалы технологического проекта

В публичном репозитории оставлены два актуальных итоговых документа:

- `AgentLangGraph_NIR_defense_2026-09-16.pptx` — презентация защиты;
- `AgentLangGraph_technology_report_GOST_2026-09-16.pdf` — технический отчёт,
  оформленный на русском языке по требованиям ГОСТ.

Числа в этих материалах восстанавливаются из сохранённых результатов в
`artifacts/`. Методика, условия сравнения и ограничения описаны в техническом
отчёте и в `docs/research/TECHNOLOGY_PROJECT_COMPARISON_2026_09_11.md`.

Редактируемые исходники, передаточные ZIP-пакеты и предыдущие версии материалов
не входят в публичный комплект. Входные данные, схемы и скрипты экспериментов
доступны в `benchmark/`, `experiments/` и `scripts/`.
