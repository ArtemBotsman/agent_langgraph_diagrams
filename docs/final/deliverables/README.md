# Технический отчёт

Актуальный документ: [AgentLangGraph_technology_report_GOST.pdf](AgentLangGraph_technology_report_GOST.pdf).
В нём описаны исправления, условия внешнего сравнения, результаты и различия
исследовательского и демонстрационного профилей.

Внутри PDF, на 27 страницах, находятся схема архитектуры и графики сравнения
содержания, времени и цены, F1/Recall по размерам и выполнения температурного пилота.
В приложениях сохранены семь дополнительно предоставленных иллюстраций
с пояснениями и итогом по задачам проекта и замечаниям комиссии.
