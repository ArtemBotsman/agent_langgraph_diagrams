Use Case: UC-002 — Управление очередью приготовления заказов
Goal: Сотрудник кафе просматривает активные заказы в очереди приготовления, отсортированной по времени самовывоза, и последовательно изменяет статус заказа.
Primary actor: ACT-002
Trigger: Сотрудник кафе открывает экран очереди приготовления.
Preconditions:
  - PRE-UC002-001: Сотрудник кафе авторизован и имеет доступ к экрану очереди приготовления.
  - PRE-UC002-002: В системе есть активные заказы.
Main success scenario:
  1. [STEP-UC002-001] Сотрудник кафе открывает экран очереди приготовления.
  2. [STEP-UC002-002] Сотрудник кафе выбирает заказ в очереди.
  3. [STEP-UC002-003] Сотрудник кафе изменяет статус заказа на «принят».
  4. [STEP-UC002-004] Сотрудник кафе изменяет статус заказа на «готовится».
  5. [STEP-UC002-005] Сотрудник кафе изменяет статус заказа на «готов».
  6. [STEP-UC002-006] Сотрудник кафе изменяет статус заказа на «выдан».
Exception scenarios:
  - SCN-UC002-EXC-001: Попытка изменить статус заказа вне допустимой последовательности
Source FRs: FR-007, FR-008
