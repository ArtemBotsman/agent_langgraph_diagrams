Use Case: UC-007 — Просмотр очереди приготовления
Goal: Сотрудник кафе просматривает активные заказы в очереди приготовления, отсортированной по времени самовывоза.
Primary actor: ACT-002
Trigger: Сотрудник кафе открывает экран очереди приготовления.
Preconditions:
  - PRE-UC007-001: Сотрудник кафе авторизован.
Main success scenario:
  1. [STEP-UC007-001] Сотрудник кафе открывает экран очереди приготовления.
  2. [STEP-UC007-002] Система загружает активные заказы, отсортированные по времени самовывоза.
Exception scenarios:
  - SCN-UC007-EXC-001: Ошибка загрузки очереди
