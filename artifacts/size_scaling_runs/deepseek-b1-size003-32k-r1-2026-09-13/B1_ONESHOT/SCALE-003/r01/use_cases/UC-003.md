Use Case: UC-003 — Управление корзиной
Goal: Клиент добавляет позиции в корзину, изменяет их количество и удаляет их из корзины.
Primary actor: ACT-001
Trigger: Клиент добавляет позицию меню в корзину или изменяет содержимое корзины.
Preconditions:
  - PRE-UC003-001: Клиент выбрал позицию меню с обязательным размером и доступными модификаторами.
Main success scenario:
  1. [STEP-UC003-001] Клиент добавляет выбранную позицию меню в корзину.
  2. [STEP-UC003-002] Клиент изменяет количество позиции в корзине.
  3. [STEP-UC003-003] Клиент удаляет позицию из корзины.
Exception scenarios:
  - SCN-UC003-EXC-001: Ошибка изменения корзины
Source FRs: FR-003
