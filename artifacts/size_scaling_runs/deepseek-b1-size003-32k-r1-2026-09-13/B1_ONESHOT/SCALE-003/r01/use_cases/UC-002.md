Use Case: UC-002 — Выбор размера и модификаторов позиции меню
Goal: Клиент выбирает обязательный размер и доступные модификаторы позиции меню до добавления её в корзину.
Primary actor: ACT-001
Trigger: Клиент выбирает позицию меню для добавления в корзину.
Preconditions:
  - PRE-UC002-001: Клиент просматривает меню.
Main success scenario:
  1. [STEP-UC002-001] Клиент выбирает позицию меню для добавления в корзину.
  2. [STEP-UC002-002] Клиент выбирает обязательный размер позиции меню.
  3. [STEP-UC002-003] Клиент выбирает доступные модификаторы позиции меню.
Exception scenarios:
  - SCN-UC002-EXC-001: Не выбран обязательный размер
Source FRs: FR-002
