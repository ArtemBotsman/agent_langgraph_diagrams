Use Case: UC-005 — Отправка заказа
Goal: Клиент отправляет заказ, указав имя и номер телефона.
Primary actor: ACT-001
Trigger: Клиент нажимает кнопку отправки заказа.
Preconditions:
  - PRE-UC005-001: В корзине есть хотя бы одна позиция.
  - PRE-UC005-002: Выбран интервал самовывоза.
Main success scenario:
  1. [STEP-UC005-001] Клиент вводит имя.
  2. [STEP-UC005-002] Клиент вводит номер телефона.
  3. [STEP-UC005-003] Клиент нажимает кнопку отправки заказа.
Exception scenarios:
  - SCN-UC005-EXC-001: Ошибка валидации данных заказа
Source FRs: FR-005
