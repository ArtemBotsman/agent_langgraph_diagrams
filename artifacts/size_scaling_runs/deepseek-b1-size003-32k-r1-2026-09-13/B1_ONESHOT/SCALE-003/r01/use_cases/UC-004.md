Use Case: UC-004 — Выбор интервала самовывоза
Goal: Клиент выбирает один доступный интервал самовывоза из предложенных на текущий день.
Primary actor: ACT-001
Trigger: Клиент переходит к выбору времени самовывоза.
Preconditions:
  - PRE-UC004-001: В корзине есть хотя бы одна позиция.
Main success scenario:
  1. [STEP-UC004-001] Клиент переходит к выбору времени самовывоза.
  2. [STEP-UC004-002] Клиент выбирает один доступный интервал самовывоза.
Exception scenarios:
  - SCN-UC004-EXC-001: Нет доступных интервалов самовывоза
Source FRs: FR-004
