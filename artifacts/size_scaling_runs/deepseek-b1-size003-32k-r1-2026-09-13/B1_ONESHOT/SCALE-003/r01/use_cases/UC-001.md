Use Case: UC-001 — Просмотр меню
Goal: Клиент видит доступные позиции меню, сгруппированные по категориям, с названием, описанием, ценой и признаком отсутствия в продаже.
Primary actor: ACT-001
Trigger: Клиент открывает клиентскую страницу приложения.
Preconditions:
  - PRE-UC001-001: Клиентская страница приложения доступна.
Main success scenario:
  1. [STEP-UC001-001] Клиент открывает клиентскую страницу приложения.
  2. [STEP-UC001-002] Система загружает доступные позиции меню, сгруппированные по категориям, с названием, описанием, ценой и признаком отсутствия в продаже.
Exception scenarios:
  - SCN-UC001-EXC-001: Ошибка загрузки меню
Source FRs: FR-001
