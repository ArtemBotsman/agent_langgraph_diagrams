Use Case: UC-001 — Заменить неформальную таблицу бронирований оборудования понятным календарём доступности и самостоятельным резервированием без пересечений.
Goal: Заменить неформальную таблицу бронирований оборудования понятным календарём доступности и самостоятельным резервированием без пересечений.
Primary actor: ACT-001
Trigger: User starts the requested process
Preconditions:
Main success scenario:
  1. [STEP-UC001-001] Сотрудник студии должен иметь возможность войти в систему с помощью адреса электронной почты и пароля.
  2. [STEP-UC001-002] Авторизованный сотрудник должен иметь возможность просматривать карточки оборудования с названием, категорией, идентификатором и текущим статусом доступности.
  3. [STEP-UC001-003] Сотрудник должен иметь возможность просматривать календарь существующих бронирований и периодов технического обслуживания для выбранной единицы оборудования.
  4. [STEP-UC001-004] Сотрудник должен иметь возможность забронировать свободную единицу оборудования на указанные дату и время начала и дату и время окончания.
  5. [STEP-UC001-005] Система должна отклонять бронирование, временной интервал которого пересекается с существующим бронированием или периодом технического обслуживания той же единицы оборудования.
  6. [STEP-UC001-006] Сотрудник должен иметь возможность отменить только собственное будущее бронирование.
  7. [STEP-UC001-007] Координатор оборудования должен иметь возможность создать для единицы оборудования период технического обслуживания с датами и причиной.
Source FRs: FR-001, FR-002, FR-003, FR-004, FR-005, FR-006, FR-007
