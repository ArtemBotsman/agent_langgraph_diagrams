Use Case: UC-001 — Сократить очереди у кассы, позволив гостям заранее оформлять заказы на самовывоз, а сотрудникам — проводить их по простому процессу приготовления.
Goal: Сократить очереди у кассы, позволив гостям заранее оформлять заказы на самовывоз, а сотрудникам — проводить их по простому процессу приготовления.
Primary actor: ACT-001
Trigger: User starts the requested process
Preconditions:
Main success scenario:
  1. [STEP-UC001-001] На клиентской странице должны отображаться доступные позиции меню, сгруппированные по категориям, с названием, описанием, ценой и признаком отсутствия в продаже.
  2. [STEP-UC001-002] Клиент должен иметь возможность выбрать обязательный размер и доступные модификаторы позиции меню до добавления её в корзину.
  3. [STEP-UC001-003] Клиент должен иметь возможность добавлять позиции в корзину, изменять их количество и удалять их из корзины.
  4. [STEP-UC001-004] Клиент должен иметь возможность выбрать один доступный интервал самовывоза из предложенных на текущий день.
  5. [STEP-UC001-005] Клиент должен иметь возможность отправить заказ, указав имя и номер телефона.
  6. [STEP-UC001-006] После отправки система должна присвоить заказу номер и показать заказанные позиции, итоговую сумму и время самовывоза.
  7. [STEP-UC001-007] Сотрудники кафе должны иметь возможность просматривать активные заказы в очереди приготовления, отсортированной по времени самовывоза.
  8. [STEP-UC001-008] Сотрудники кафе должны иметь возможность последовательно изменять статус заказа на «принят», «готовится», «готов» и «выдан».
