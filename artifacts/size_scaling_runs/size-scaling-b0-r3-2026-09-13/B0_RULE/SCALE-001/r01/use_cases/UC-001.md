Use Case: UC-001 — Дать небольшому салону возможность принимать записи онлайн, предоставить клиентам понятное самообслуживание, а сотрудникам — достоверное расписание и учёт посещений на день.
Goal: Дать небольшому салону возможность принимать записи онлайн, предоставить клиентам понятное самообслуживание, а сотрудникам — достоверное расписание и учёт посещений на день.
Primary actor: ACT-001
Trigger: User starts the requested process
Preconditions:
Main success scenario:
  1. [STEP-UC001-001] На публичной странице должна отображаться каждая доступная для записи услуга с названием, продолжительностью и ценой.
  2. [STEP-UC001-002] Клиент должен иметь возможность просматривать свободные временные слоты для выбранной услуги, выбранного сотрудника и выбранной даты.
  3. [STEP-UC001-003] Клиент должен иметь возможность создать запись, указав имя, номер телефона, адрес электронной почты, услугу, сотрудника и свободный временной слот.
  4. [STEP-UC001-004] После создания записи система должна присвоить ей уникальный код бронирования и показать подтверждённые данные записи.
  5. [STEP-UC001-005] Клиент должен иметь возможность отменить будущую запись, указав код бронирования и адрес электронной почты, использованный при записи.
  6. [STEP-UC001-006] Сотрудник должен иметь возможность открыть расписание на день и установить для записи статус «завершена» или «неявка».
Source FRs: FR-001, FR-002, FR-003, FR-004, FR-005, FR-006
