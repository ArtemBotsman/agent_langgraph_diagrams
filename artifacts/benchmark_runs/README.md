# Реестр экспериментальных запусков

Эта папка хранит воспроизводимые артефакты экспериментов. Не все каталоги
являются успешными: неудачные запуски сохранены как отрицательное
экспериментальное свидетельство, а не удалены задним числом.

Основной повторный эксперимент:

- `repeated-b0-b1-full-dev001-2026-09-09/` — два повтора B0, B1 и FULL на одном
  development-case (кейсе разработки) `B1-DEV-001`;
- `full-live-pilot-v3-2026-09-09/` — успешный артефакт полного графа с двумя
  activity-диаграммами;
- более ранние `b1-live-*` и `full-live-*` — диагностические прогоны, по которым
  исправлялись ограничение токенов, схема ответа критика и схема trace manifest
  (манифеста трассировки).

Журналы содержат техническую телеметрию и хэши, но не содержат API key
(ключ API), полные prompts (инструкции) или полные ответы модели.

Hidden gold (скрытые эталоны) не использовались для настройки или этих живых
пилотных запусков.
