# Pyreverse как полезный смежный baseline

Pyreverse (инструмент статического анализа Python-кода) применён к текущему
репозиторию после появления кода. Получено:

- 28 Python-модулей;
- 54 импортные связи;
- class/package Mermaid и PNG (классовое и пакетное представление).

Это полезный смежный baseline (базовая линия соседней постановки), потому что он
показывает, какую структуру можно извлечь детерминированно из уже существующего
кода. Он не является прямым конкурентом исследуемому pipeline (конвейеру): не
принимает SpecificationReq, не интерпретирует бизнес-смысл требований и не
создаёт поведенческие activity-диаграммы до написания кода.
