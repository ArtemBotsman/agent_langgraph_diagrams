Use Case: UC-001 — Allow attendees to register for events and organisers to control capacity.
Goal: Allow attendees to register for events and organisers to control capacity.
Primary actor: ACT-001
Trigger: User starts the requested process
Preconditions:
Main success scenario:
  1. [STEP-UC001-001] An organiser can publish an event with a capacity and registration deadline.
  2. [STEP-UC001-002] An attendee can register while registration is open; if capacity is exhausted, the system adds the attendee to a waiting list.
  3. [STEP-UC001-003] The system promotes the first waiting attendee when a confirmed registration is cancelled.
Source FRs: FR-001, FR-002, FR-003
