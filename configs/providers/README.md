# Provider presets

Эти файлы содержат только безопасные примеры настроек. Рабочий секрет хранится
в корневом `.env` и не попадает в Git.

- `deepseek.env.example` — текущий проверенный основной провайдер.
- `groq-qwen.env.example` — подготовленный профиль для малого сравнительного
  пилота Qwen на Groq Free Plan.
- `openai.env.example` — безопасная заготовка OpenAI без ключа и без
  предположения о доступной модели. Точный `LLM_MODEL` выбирается из списка,
  который возвращает API для конкретного ключа.
- `anthropic.env.example` — Claude Opus 5 через нативный Anthropic Messages
  API. Локальная рабочая копия хранится в `.env.claude` и исключена из Git.

Перед сменой провайдера скопируйте нужные значения в `.env`, добавьте свой ключ
и используйте отдельный `experiment_id`. Не смешивайте результаты двух моделей
в одном условии эксперимента.

Для OpenAI рекомендуется отдельный локальный файл `.env.openai`, уже
исключённый из Git. После добавления `OPENAI_API_KEY` список доступных моделей
можно получить безопасной командой:

```bash
poetry run python scripts/list_available_models.py \
  --env-file .env.openai --contains gpt
```

Ключ не выводится. Наличие модели в списке подтверждает доступ аккаунта, но
совместимость с текущим Chat Completions adapter проверяется отдельным одним
ограниченным тестовым вызовом.

Для сопоставимого внешнего one-shot пилота OpenAI/Claude используется
`scripts/run_external_one_shot_api.py`. Он сохраняет каждый ответ сразу,
поддерживает до трёх параллельных повторов и требует явный верхний предел
расчётной стоимости. Raw responses и оба локальных файла с ключами исключены
из Git.
