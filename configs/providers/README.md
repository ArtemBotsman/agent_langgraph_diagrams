# Provider presets

Эти файлы содержат только безопасные примеры настроек. Рабочий секрет хранится
в корневом `.env` и не попадает в Git.

- `deepseek.env.example` — текущий проверенный основной провайдер.
- `groq-qwen.env.example` — подготовленный профиль для малого сравнительного
  пилота Qwen на Groq Free Plan.

Перед сменой провайдера скопируйте нужные значения в `.env`, добавьте свой ключ
и используйте отдельный `experiment_id`. Не смешивайте результаты двух моделей
в одном условии эксперимента.
